# pynq-board-lab（此前已交付的通用PYNQ技能）

## 适用范围

排查 PYNQ 板卡的上电、SD 启动、网络/Jupyter 连接、存储容量与残留进程问题；适用于板卡准备和环境诊断，不替代具体 IP 的 DMA 驱动或模型数值验证。

## 使用方法

先读[SKILL.md](SKILL.md)，使用其中引用的参考或脚本；在支持技能的环境调用 `$pynq-board-lab`。板型、接口和授权以当前工程为准，不以头盔项目固定常量代替。

## 失效条件

读到的是当前主机信息；电脑结果不证明板卡启动成功，板型/跳线/网络不同需另核对。

## 已验证效果

此前六项技能已通过结构与35项主机检查；本次副本也参与目录/哈希/脚本检查，记录见[validation.json](../../validation.json)。没有因加载技能就运行硬件。

## 经验来源与项目区别

由本项目的供电/启动、DMA生命周期、数值对照、预览竞争、重复计时、核快整层慢等问题抽象。属于换题目/板卡可调整后复用的方法；项目定制流程另在[project/](../../project/)区，不计作新增项目技能。
