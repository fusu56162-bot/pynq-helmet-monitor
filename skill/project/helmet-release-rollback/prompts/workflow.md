# 可直接使用的任务提示词：发布包身份、完整备份与回退

请结合当前四类224输入、178-DSP前段加ARM续算项目，完成以下任务：
整理交付、恢复误删文件、检查完整备份及候选版本隔离。

我提供的材料位置（按实际填写，不存在就标缺失）：
- 原发布包与SHA256清单
- 待核验目录或结果ZIP
- 电脑上完整备份的位置与校验记录

先读取本目录README.md以及../../_shared/project_profile.json。用户当前约束覆盖历史默认配置；不擅自恢复已取消功能，不以历史测量填充本次结果。

执行与判断：
1. 区分完整traffic_project归档、MANIFEST和小结果ZIP，记录各自覆盖范围。
2. 先用verify_manifest检查原文件，缺失文档从原包按字节恢复，不重算原清单掩盖差异。
3. 浏览器临时下载后缀仍在时不视为完整归档；核对大小、可读性及哈希。
4. 候选另建目录，回退引用已核验的模型/bit/HWH组合；只读检查不删除SD内容。

输出：
- 文件身份报告
- 备份覆盖范围表
- 明确的恢复对象和回退入口

在结尾单独说明：只有核验ZIP不能恢复完整工程。; 模型、位流或HWH任一不匹配时不能宣称恢复发布版。; 重写哈希会毁掉原发布身份；应另立新版本。
区分历史验证、本次离线检查、仍需板端实测。不要把数值一致、识别精度和速度收益混为同一个通过标志。
