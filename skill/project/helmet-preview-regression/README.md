# 19 双预览竞争退化的定位与回退

**形式：** 负结果技能＋受控A/B清单。**定位：** 当前四类224输入头盔检测项目的经验包，不是新的板端实验结果。

## 适用范围

解释原始预览与识别分离后ARM续算变慢，避免将双线程等同自动提速。

## 所需输入

- 原单画面与双画面同口径结果
- ARM线程/解码/JPEG开销
- 图像ID与CPU占用/频率信息

共享事实先读[项目契约](../../_shared/project_profile.json)。其中类别、阈值、地址、100MHz和178DSP仅适用当前发布版。

## 使用方法

让助手读取本目录SKILL.md，或在支持技能发现的环境调用 `$helmet-preview-regression`；将材料位置填入[prompts/workflow.md](prompts/workflow.md)，按下面顺序执行。

1. 核对模型/硬件是否未变，先查新增预览线程做了哪些解码、缩放、编码和提交。
2. 比较完整forward与嵌套ARM段，区分计算退化与相机启动失败。
3. 在可比场景下只关预览做A/B；没有频率/带宽证据时只列竞争解释为推断。
4. 若端到端更新率退化，恢复单画面入口；不把快预览标成快识别，也不把旧框贴新帧冒充同帧。

结果填入[assets/record-template.json](assets/record-template.json)。它是未执行模板，空值不代表通过。

可复验命令（从含skill/的目录执行）：

```bash
python skill/_shared/tools/summarize_run.py skill/_shared/fixtures/camera_result_excerpt.json
```

`--root .`与manifest.json用于完整源码包；独立技能ZIP不含生产模型/位流，需提供匹配源码根目录。

## 交付物

- 新增负载清单
- 同口径回归对照
- 回退方案与未确认原因

## 失效条件与停止边界

- 原始预览5FPS与识别1FPS不是同一指标。
- 只看CPU百分比不能确定DDR或降频是根因。
- 异步旧框需要年龄/ID标识，不能隐去。

用户只要求分析或手动上板时，完成离线分析/可运行交付后给操作步骤，不自行触发真实设备实验。其他题目先替换模型、布局、时钟、地址和评估定义，再重新验证。

## 已验证的效果

**历史项目证据：** 返回档案双预览识别约1.142FPS、原单画面约2.408FPS；forward约476ms对224ms，已据此保留单画面发布路线。

## 从哪些失败或观察中提炼

来自预览识别分离实测退化后用户决定不要原始双画面。
