# 可直接使用的任务提示词：四类标注接收与空场甄别

请结合当前四类224输入、178-DSP前段加ARM续算项目，完成以下任务：
接收Make Sense/YOLO标签，检查中文类别映射、缺标签和真实空场。

我提供的材料位置（按实际填写，不存在就标缺失）：
- images与labels目录
- 导出类别文件/明确ID顺序
- 人工确认空场名单和按片段分组信息

先读取本目录README.md以及../../_shared/project_profile.json。用户当前约束覆盖历史默认配置；不擅自恢复已取消功能，不以历史测量填充本次结果。

执行与判断：
1. 先查类别ID映射，中文名称可以映射但不能凭显示名称推断数字顺序。
2. 每张可见目标完整标ebike、rider、对应helmet_head或bare_head；只标头部的旧数据另列partial。
3. 缺失txt标为待处理，不自动当空场；有确认名单才给缺失图空场身份。
4. 检查每行5字段、类ID、归一化范围、宽高和越界；相邻视频帧按片段分组防止泄漏。

输出：
- 标签格式与覆盖报告
- 已确认空场/未标注/部分标注列表
- 可训练与独立评估划分建议

在结尾单独说明：无classes映射时无法确定类别语义。; 有目标却缺标签会产生错误负样本。; 同一骑行片段相邻帧分到训练和测试会高估泛化。
区分历史验证、本次离线检查、仍需板端实测。不要把数值一致、识别精度和速度收益混为同一个通过标志。
