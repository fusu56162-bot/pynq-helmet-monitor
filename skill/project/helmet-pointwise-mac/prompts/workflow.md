# 可直接使用的任务提示词：1×1通道分块与可复用乘加阵列

请结合当前四类224输入、178-DSP前段加ARM续算项目，完成以下任务：
基于当前模型热点评估1×1卷积的输入/输出通道并行与权重复用。

我提供的材料位置（按实际填写，不存在就标缺失）：
- 目标层Cin/Cout/H/W、groups和布局
- 当前ARM整层时间及量化尺度
- 可用DSP/BRAM、片上端口和既有接口约束

先读取本目录README.md以及../../_shared/project_profile.json。用户当前约束覆盖历史默认配置；不擅自恢复已取消功能，不以历史测量填充本次结果。

执行与判断：
1. 把1×1建模为通道归约，不额外设计3×3行缓存。
2. 选择Pi/Po分块，让同一输入tile服务多个输出通道，部分和保留至全部Cin完成。
3. 按最坏输入/权重和归约长度推导累加位宽，处理余数通道和bias/rounding。
4. 比较pack+搬运+核+激活+布局对原ARM整层，未取得收益前不接替摄像头发布入口。

输出：
- 通道tiling与部分和方案
- DSP/BRAM/端口预算
- 数值参考和整层A/B计划

在结尾单独说明：独立整数tile快不代表整个1×1或YOLO快。; 每tile提前量化/激活会改变原算法。; 原ARM参考采集不能称1×1硬件优化成功。
区分历史验证、本次离线检查、仍需板端实测。不要把数值一致、识别精度和速度收益混为同一个通过标志。
