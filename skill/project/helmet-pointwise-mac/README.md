# 11 1×1通道分块与可复用乘加阵列

**形式：** 硬件提示词工作流＋设计模板。**定位：** 当前四类224输入头盔检测项目的经验包，不是新的板端实验结果。

## 适用范围

基于当前模型热点评估1×1卷积的输入/输出通道并行与权重复用。

## 所需输入

- 目标层Cin/Cout/H/W、groups和布局
- 当前ARM整层时间及量化尺度
- 可用DSP/BRAM、片上端口和既有接口约束

共享事实先读[项目契约](../../_shared/project_profile.json)。其中类别、阈值、地址、100MHz和178DSP仅适用当前发布版。

## 使用方法

让助手读取本目录SKILL.md，或在支持技能发现的环境调用 `$helmet-pointwise-mac`；将材料位置填入[prompts/workflow.md](prompts/workflow.md)，按下面顺序执行。

1. 把1×1建模为通道归约，不额外设计3×3行缓存。
2. 选择Pi/Po分块，让同一输入tile服务多个输出通道，部分和保留至全部Cin完成。
3. 按最坏输入/权重和归约长度推导累加位宽，处理余数通道和bias/rounding。
4. 比较pack+搬运+核+激活+布局对原ARM整层，未取得收益前不接替摄像头发布入口。

结果填入[assets/record-template.json](assets/record-template.json)。它是未执行模板，空值不代表通过。

## 交付物

- 通道tiling与部分和方案
- DSP/BRAM/端口预算
- 数值参考和整层A/B计划

## 失效条件与停止边界

- 独立整数tile快不代表整个1×1或YOLO快。
- 每tile提前量化/激活会改变原算法。
- 原ARM参考采集不能称1×1硬件优化成功。

用户只要求分析或手动上板时，完成离线分析/可运行交付后给操作步骤，不自行触发真实设备实验。其他题目先替换模型、布局、时钟、地址和评估定义，再重新验证。
