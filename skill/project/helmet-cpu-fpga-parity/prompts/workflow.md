# 可直接使用的任务提示词：同输入CPU/FPGA逐位一致性验收

请结合当前四类224输入、178-DSP前段加ARM续算项目，完成以下任务：
区分同输入实现正确与识别精度，验证当前178前段加ARM续算。

我提供的材料位置（按实际填写，不存在就标缺失）：
- 同一输入的CPU raw、FPGA raw与边界
- 模型/硬件身份
- 明确逐位或容差规则

先读取本目录README.md以及../../_shared/project_profile.json。用户当前约束覆盖历史默认配置；不擅自恢复已取消功能，不以历史测量填充本次结果。

执行与判断：
1. 先核shape/dtype，再查有限值和位模式，不只对最终框。
2. 定点、打包及当前精确参考按逐位；任何近似实现另立事先约定容差。
3. 完整forward与边界同时检验；未抽查帧不标CPU EXACT。
4. 用归档真实数组复现校验，明确这次离线重验未运行FPGA。

输出：
- 逐位/容差检查JSON
- 首个差异位置与最大绝对差诊断
- 数值验收与精度验收分开的结论

在结尾单独说明：NaN即使两边相同也不通过有限值检查。; 模型/输入不同的两个数组不能据此归因硬件。; 0.73置信度或框相近不能代替raw一致性。
区分历史验证、本次离线检查、仍需板端实测。不要把数值一致、识别精度和速度收益混为同一个通过标志。
