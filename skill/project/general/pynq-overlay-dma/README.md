# pynq-overlay-dma（此前已交付的通用PYNQ技能）

## 适用范围

接入或排查 PYNQ 自定义 Overlay、AXI DMA/VDMA 与 PS/PL 缓冲区通路，核对 bit/HWH、IP 地址、时钟、协议与内存所有权；用于硬件接口及传输问题，不把软件模拟视为上板通过。

## 使用方法

先读[SKILL.md](SKILL.md)，使用其中引用的参考或脚本；在支持技能的环境调用 `$pynq-overlay-dma`。板型、接口和授权以当前工程为准，不以头盔项目固定常量代替。

## 失效条件

bit/HWH或设备地址不匹配、所有权未知、DMA未确认停止时不能继续写寄存器或释放内存。

## 已验证效果

此前六项技能已通过结构与35项主机检查；本次副本也参与目录/哈希/脚本检查，记录见[validation.json](../../validation.json)。没有因加载技能就运行硬件。

## 经验来源与项目区别

由本项目的供电/启动、DMA生命周期、数值对照、预览竞争、重复计时、核快整层慢等问题抽象。属于换题目/板卡可调整后复用的方法；项目定制流程另在[project/](../../project/)区，不计作新增项目技能。
