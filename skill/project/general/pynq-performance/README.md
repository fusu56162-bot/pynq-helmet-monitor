# pynq-performance（此前已交付的通用PYNQ技能）

## 适用范围

分析 PYNQ 实测日志/JSON，区分采集、完整推理、ARM续算、显示和后台保存计时，设计同通路 A/B 并判断收益；用于低帧率与加速效果争议，不代替精度或 DMA 安全核验。

## 使用方法

先读[SKILL.md](SKILL.md)，使用其中引用的参考或脚本；在支持技能的环境调用 `$pynq-performance`。板型、接口和授权以当前工程为准，不以头盔项目固定常量代替。

## 失效条件

不同口径、嵌套计时或并行阶段不能直接相加，缺指标不能补零或PASS。

## 已验证效果

此前六项技能已通过结构与35项主机检查；本次副本也参与目录/哈希/脚本检查，记录见[validation.json](../../validation.json)。没有因加载技能就运行硬件。

## 经验来源与项目区别

由本项目的供电/启动、DMA生命周期、数值对照、预览竞争、重复计时、核快整层慢等问题抽象。属于换题目/板卡可调整后复用的方法；项目定制流程另在[project/](../../project/)区，不计作新增项目技能。
