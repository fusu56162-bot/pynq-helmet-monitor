# pynq-model-parity（此前已交付的通用PYNQ技能）

## 适用范围

更换或接入 PYNQ 推理模型时核对预处理、张量布局、量化和解码契约，逐段比较 CPU/FPGA 同输入结果；适用于 ONNX/ncnn 等模型转换与板端数值验收，不把数值一致当作识别精度。

## 使用方法

先读[SKILL.md](SKILL.md)，使用其中引用的参考或脚本；在支持技能的环境调用 `$pynq-model-parity`。板型、接口和授权以当前工程为准，不以头盔项目固定常量代替。

## 失效条件

缺相同输入或未声明误差规则时不能判断；数值相同不证明精度达标。

## 已验证效果

此前六项技能已通过结构与35项主机检查；本次副本也参与目录/哈希/脚本检查，记录见[validation.json](../../validation.json)。没有因加载技能就运行硬件。

## 经验来源与项目区别

由本项目的供电/启动、DMA生命周期、数值对照、预览竞争、重复计时、核快整层慢等问题抽象。属于换题目/板卡可调整后复用的方法；项目定制流程另在[project/](../../project/)区，不计作新增项目技能。
