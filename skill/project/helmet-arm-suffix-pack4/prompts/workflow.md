# 可直接使用的任务提示词：ARM续算、NEON与pack4边界成本

请结合当前四类224输入、178-DSP前段加ARM续算项目，完成以下任务：
在前段已由FPGA处理后，定位ncnn续算和布局/所有权转换的真实成本。

我提供的材料位置（按实际填写，不存在就标缺失）：
- 同通路forward与owned_pack_and_suffix计时
- ncnn线程/NEON/编译选项
- 边界HWC与pack4代码及层级热点

先读取本目录README.md以及../../_shared/project_profile.json。用户当前约束覆盖历史默认配置；不擅自恢复已取消功能，不以历史测量填充本次结果。

执行与判断：
1. 把续算看作forward子区间，不与forward重复相加；该段合并计时不能直接全归某个1×1算子。
2. 核查已有NEON和2线程，测布局、Mat所有权复制、缓存与剩余卷积/SiLU，不盲减线程。
3. 一次改一项并交错同输入A/B，比较数值、均值/中位数/尾部。
4. 若内存池或线程调整无收益，保存负结果，转向实测算子/数据流热点。

输出：
- 续算与桥接成本拆分
- 软件/硬件候选优先级
- 同输入验证与收益界限

在结尾单独说明：线程更多或更少都不自动更快。; 154ms离线续算与187ms摄像头续算运行负载不同。; 不能把所有ARM耗时都叫YOLO或1×1耗时。
区分历史验证、本次离线检查、仍需板端实测。不要把数值一致、识别精度和速度收益混为同一个通过标志。
