# 可直接使用的任务提示词：精确激活与再量化ROM生成

请结合当前四类224输入、178-DSP前段加ARM续算项目，完成以下任务：
将本项目受限量化域的ARM数值行为转为匹配新权重的片上查表。

我提供的材料位置（按实际填写，不存在就标缺失）：
- 真实ARM scale/bias/input scales
- 逐通道可达整数域
- 原激活与rounding/量化实现

先读取本目录README.md以及../../_shared/project_profile.json。用户当前约束覆盖历史默认配置；不擅自恢复已取消功能，不以历史测量填充本次结果。

执行与判断：
1. 从ARM原实现采集映射而非换近似公式，区分输入规范化表和层间激活再量化表。
2. 逐通道核对上下界、符号、索引、表项覆盖与域外行为。
3. 生成ROM和常量身份，检查容量/端口，再对黄金张量逐位比较。
4. 权重/尺度变化后重新确认域，不能复用上一模型的查表证明。

输出：
- 域覆盖与表项统计
- ROM布局/哈希和资源估算
- 逐通道等价结果

在结尾单独说明：只抽查几项无法证明整个查表域精确。; 索引截断、饱和边界和负数rounding会造成隐藏误差。; 近似SiLU不能写成逐位无损。
区分历史验证、本次离线检查、仍需板端实测。不要把数值一致、识别精度和速度收益混为同一个通过标志。
