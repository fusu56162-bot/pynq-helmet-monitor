# 可直接使用的任务提示词：固定224四类训练与轮次归档

请结合当前四类224输入、178-DSP前段加ARM续算项目，完成以下任务：
继续训练当前轻量模型，保持单次整图四类能力与可比验证，不接管云账户。

我提供的材料位置（按实际填写，不存在就标缺失）：
- 固定训练脚本/YOLOv5版本
- 按场景划分的数据清单
- 上一轮best/last、日志和验证集范围

先读取本目录README.md以及../../_shared/project_profile.json。用户当前约束覆盖历史默认配置；不擅自恢复已取消功能，不以历史测量填充本次结果。

执行与判断：
1. 保持224输入和四类顺序，先小规模smoke确认数据/验证/保存链能完成。
2. 记录初始化权重、seed、batch、workers、学习率、增强与early-stopping设置；训练轮数不等于独立实验轮次。
3. 需要训练满时明确禁用早停，同时保留best与last，不能把最后epoch当自动最佳。
4. 按相同验证集比较每类TP/FP/FN、P/R和mAP；训练后导出固定接口候选，不直接覆盖现场模型。

输出：
- 可执行训练参数表
- 轮次及checkpoint身份表
- 每类验证结果与未达标项

在结尾单独说明：在新镜像里混用旧虚拟环境可能重新拉错Torch。; mAP或某个epoch最大值不能拼成同时满足所有目标的模型。; 校园无戴盔正样本时无法证明校园戴盔精度。
区分历史验证、本次离线检查、仍需板端实测。不要把数值一致、识别精度和速度收益混为同一个通过标志。
