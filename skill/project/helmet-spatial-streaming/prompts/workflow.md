# 可直接使用的任务提示词：3×3紧凑输入、行缓存与整层启动

请结合当前四类224输入、178-DSP前段加ARM续算项目，完成以下任务：
避免ARM重复复制邻域，设计3×3滑窗、输入/计算/输出流水与完整层测试。

我提供的材料位置（按实际填写，不存在就标缺失）：
- kernel/stride/padding/dilation/groups
- 紧凑输入与输出布局
- ARM各阶段成本和候选HLS/RTL

先读取本目录README.md以及../../_shared/project_profile.json。用户当前约束覆盖历史默认配置；不擅自恢复已取消功能，不以历史测量填充本次结果。

执行与判断：
1. 按可达输入设计预填、三行缓存、左右padding、stride和尾部drain；dilation变化需重算行数。
2. 整层一次启动，保留各阶段token数、FIFO深度与回压检查。
3. 目标为减少展开/重复搬运，不把DDR带宽和端口竞争省略。
4. 先数值后整层时间；若候选更慢，保留负结果而不是称流式必然更快。

输出：
- 滑窗与边界时序表
- 完整层端到端成本表
- 数值通过/速度通过两项结论

在结尾单独说明：DATAFLOW pragma不保证实际阶段重叠。; 输出FIFO未消费或TLAST错误会死锁。; 裸核时间不能对比完整ARM层。
区分历史验证、本次离线检查、仍需板端实测。不要把数值一致、识别精度和速度收益混为同一个通过标志。
