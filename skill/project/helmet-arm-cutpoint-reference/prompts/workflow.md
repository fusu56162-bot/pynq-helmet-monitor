# 可直接使用的任务提示词：ARM切分点与续算参考采集

请结合当前四类224输入、178-DSP前段加ARM续算项目，完成以下任务：
在前两层硬件化前确定ncnn边界与可恢复的原ARM输出。

我提供的材料位置（按实际填写，不存在就标缺失）：
- 现有完整ARM运行时
- 原始同输入张量
- conv0/conv1切分与续算桥源码

先读取本目录README.md以及../../_shared/project_profile.json。用户当前约束覆盖历史默认配置；不擅自恢复已取消功能，不以历史测量填充本次结果。

执行与判断：
1. 先证明新桥full与原运行时full一致，再证明boundary→resume与full一致。
2. 保存整数累加、激活前后、再量化输入和原raw输出；固定shape/dtype/layout。
3. 把ARM参考采集标明未加载新FPGA，不将其作为硬件提速结果。
4. 仅在引用稳定后生成硬件常量并接上板验证。

输出：
- 分层黄金张量索引
- full/boundary/resume等价报告
- 后续硬件接口定义

在结尾单独说明：桥接full已偏离原算子时不能用它作黄金参考。; 无清晰所有权的Mat引用可能在resume前失效。; 采集未测时间时不得补写性能。
区分历史验证、本次离线检查、仍需板端实测。不要把数值一致、识别精度和速度收益混为同一个通过标志。
