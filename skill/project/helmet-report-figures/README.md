# 25 报告结论、白底流程图与图片归因

**形式：** 报告模板＋踩坑清单。**定位：** 当前四类224输入头盔检测项目的经验包，不是新的板端实验结果。

## 适用范围

把当前四类检测与硬件加速写成正式报告，正确选择示例图和性能口径。

## 所需输入

- 比赛模板/图位要求
- 已验证功能与原始实验数据
- 实物/预测/参考拼图及版本信息

共享事实先读[项目契约](../../_shared/project_profile.json)。其中类别、阈值、地址、100MHz和178DSP仅适用当前发布版。

## 使用方法

让助手读取本目录SKILL.md，或在支持技能发现的环境调用 `$helmet-report-figures`；将材料位置填入[prompts/workflow.md](prompts/workflow.md)，按下面顺序执行。

1. 从当前已实现范围写摘要和创新点，包含YOLOv5训练、异构前段、片上复用和同帧验证，不写已取消功能。
2. 为性能/精度/资源逐条关联来源；内部对话目标和自我审查提醒改成正式客观表述。
3. 流程图白底黑字黑框，文字在框内、箭头在框外；图像不生成或补画实验成功框。
4. 示例优先真实保存预测；回放、现场、人工参考与未抽查帧分别注明。

结果填入[assets/record-template.json](assets/record-template.json)。它是未执行模板，空值不代表通过。

## 交付物

- 可用于报告的段落和图注
- 每个图位的获取条件与步骤
- 结论-证据映射表

## 失效条件与停止边界

- mAP0.752不等于75.2%板端现场成功率。
- 不能用人工REFERENCE面板作模型成功截图。
- 生成式标注照片可能改变元件细节，正式硬件取证应对照原图和手册核验。

用户只要求分析或手动上板时，完成离线分析/可运行交付后给操作步骤，不自行触发真实设备实验。其他题目先替换模型、布局、时钟、地址和评估定义，再重新验证。
